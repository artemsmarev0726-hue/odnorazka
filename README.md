# Telegram-бот розыгрыша QuickRust

Node.js 18+, без зависимостей (`npm install` не нужен).

## Запуск на Bothost
1. В @BotFather создай бота (`/newbot`), скопируй токен.
2. Залей папку на Bothost (Node.js), файл запуска — `index.js`.
3. В `config.json` впиши:
   - `token` — токен от BotFather;
   - `apiKey` — любой длинный секрет (такой же — в конфиг плагина StreamerGiveaway, поле «Ключ API»);
   - `channels` — каналы для проверки (уже вписаны @dimiki7 и @BabyYumis).
   Токен и ключ можно задать и переменными окружения `BOT_TOKEN`, `API_KEY`.
4. Включи у бота на Bothost веб-доступ (домен) — бот слушает порт из `PORT` (или `port` в config.json, по умолчанию 3000).
   Получившийся адрес `https://...bothost.tech` впиши в конфиг StreamerGiveaway → «Telegram-бот» → «Адрес».
5. **Добавь бота администратором в оба канала** (права можно не давать никакие).
   Без этого Telegram не скажет боту, подписан ли человек. В логе при запуске видно `бот администратор ✓` по каждому каналу.

## Как это работает
- Игрок в игре: меню → РОЗЫГРЫШ → «ПРИВЯЗАТЬ» у пункта Telegram → получает код.
- В боте жмёт START и присылает код → бот даёт кнопки-ссылки на каналы и «Проверить подписку».
- Плагин сам спрашивает бота о статусе; когда Discord и Telegram в порядке — кнопка «УЧАСТВУЮ» в игре становится активной.
- Один Telegram можно привязать только к одному игроку.

## Команды
- `/start`, `/status` — статус и ссылки на каналы.
- `/unlink <steamid>` — снять привязку (только для `adminIds` из config.json — твой Telegram ID числом).

## Данные
`data/state.json` — привязки Telegram ↔ SteamID. На хостинге не удалять.
